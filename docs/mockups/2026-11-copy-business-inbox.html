Frame 3: Which emails get copied.

Copied to you

  • ✓ Booking received, confirmed, declined, rescheduled, and the booking you create for a client from admin
  • ✓ Appointment reminder (24 hours before)
  • ✓ Payment receipts, bank-transfer confirmations, cart confirmations
  • ✓ Thank-you, review request and review reminder
  • ✓ Rebook reminder, "We miss you", "Your bestie booked: £10 earned"
  • ✓ Shop order confirmation and "Your order is on its way"
  • ✓ Your replies to custom-style requests
  • ✓ Batch messages: one copy per batch (marked "sent to 34 clients"), not 34 identical copies

Not copied (for the client's security)

  • ✕ Account sign-in codes and "your password was changed". A copy of a sign-in code would let anyone who reads your inbox log in as that client.
